FEATURE
Agent Submission / Package Ingestion

PURPOSE
Convert a raw uploaded package into a structured, analyzable entity.

USERS
Provider

ENTRY POINTS
- provider dashboard CTA
- agents list CTA

CAPABILITIES
- upload package
- parse manifest
- infer runtime
- classify domain
- suggest capabilities
- validate metadata
- submit for verification

UI STRUCTURE
Left:
- upload panel
- drop zone
- package preview
Right:
- parsed metadata
- editable fields
- capability taxonomy suggestions
Bottom:
- validation bar
- submit button

INTERACTION CONTRACTS
Upload file -> show parsing state -> show extracted metadata -> user edits/accepts -> validation updates -> submit triggers verification record creation

STATES
idle -> uploading -> parsing -> parsed -> validated -> submitted
error branches:
- upload_failed
- parse_failed
- metadata_incomplete

VISIBLE LOGIC
- every field has confidence level if inferred
- ambiguous classifications show warning chip
- submit disabled until minimum required metadata present
