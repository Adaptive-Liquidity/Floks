LAYOUT GRID:
- Header (sticky)
- Main: 3 columns
  Left: Identity + controls
  Center: Execution Graph
  Right: Evidence Drawer
- Bottom: Timeline / Replay

HEADER:
- Package name, badges (Verified, Cleared, Granted)
- Quick actions (Run, Export, Inspect)

TRUST STRIP:
- Knowledge Score (ring)
- Sandbox (5/5)
- Risk (Cleared)
- Sovereignty (Granted)
Each has hover explanation + click drilldown

EXECUTION GRAPH:
- Nodes: tasks/agents
- Edges: data flow
- States: pending, running, complete, failed
- Click node → open inspector

EVIDENCE DRAWER:
- Cards: title, type, confidence, source, summary
- Expand → full trace + hash

TIMELINE:
- Events with timestamps
- Click → jump to graph state

DECISION BLOCK:
- Always visible
- Shows decision, why, confidence

MOTION:
- Node activation pulse
- Progressive reveal
- Smooth drawer transitions
